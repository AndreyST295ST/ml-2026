## Модуль предобработки

### Фильтрация и матрица SNP

- Из genotype оставить колонки с префиксом `"Ca"` + идентификатор образца.
- Сохранить `final_snp_matrix.csv` размера N × M (407 × 6642).

### HW-кодирование (для CWT-ветки)

Для каждого SNP:

1. Подсчёт D (генотип 0), H (генотип 1), N.
2. \( p = (2D + H) / (2N) \), \( q = 1 - p \).
3. Замена: \( 0 \to p^2 \), \( 1 \to 2pq \), \( 2 \to q^2 \).

Назначение: сгладить сигнал для CWT, учесть популяционную структуру, нормализовать в [0, 1].

### k-мерная токенизация

- Разбиение SNP-строки на неперекрывающиеся блоки длины `k=6`.
- Хвост короче 6 → дополнение символом `'X'`.
- По обучающим данным строится словарь уникальных 6-меров → ID.
- Размер словаря: **22 778** (включая `[MASK]` с ID **22777**).
- Длина последовательности: \( 6642 / 6 = 1107 \) токенов.

### Случайное маскирование

С вероятностью `mask_prob=0.15` ID токена заменяется на ID `[MASK]`.  
Нужно для регуляризации и как механизм аугментации.

### Аугментация (баланс классов)

Исходное распределение: 90 / 113 / 140 / 64.  
Цель: **140 на класс** → итого **560** образцов.

Для меньших классов: копии последовательностей + повторное маскирование 15%.

Артефакты этапа:

- `masked_sequences_ids.csv`
- `labels.csv` (фенотипы после аугментации)
- `vocab.json` (словарь токенов)
- `token_freq_before.json` / `token_freq_after.json`

## Модуль CWT

### Расчёт

- Библиотека: **PyWavelets** (`pywt.cwt`).
- Вейвлет: комплексный Морле (`cmor`).
- Масштабы: от 1 до `min(N//4, 256)`.
- Из комплексной матрицы извлекаются: амплитуда, фаза, Re, Im.

### Сохранение изображения

1. Нормализация амплитуд → [0, 1] → [0, 255].
2. `PIL.Image` в режиме `'L'` (градации серого).
3. PNG, **300 DPI** → `data/cwt/{job_id}/sample_{id}.png`.

### Диагностические графики (для страницы «Анализ»)

- **Частотный анализ:** исходный сигнал, средняя/макс. амплитуда, фаза, Re/Im, энергия.
- **Время-частотный анализ:** спектрограммы амплитуды и фазы, доминирующие частоты, энергия по масштабам.

## Описание этапов реализации бэкенда

1. Каркас FastAPI + `config` + раздача static для CWT PNG.  
2. `UploadService` + валидация CSV / префикс `Ca`.  
3. `PreprocessingService`: матрица → k-меры → mask → аугментация.  
4. `CWTService`: HW → `pywt.cwt` → PNG + диагностики.  
5. Загрузка весов `GenomicTransformerEncoder`, `InferenceService`.  
6. `MetricsService` + `GeneImportanceService`.  
7. Фоновый `PipelineOrchestrator` + статусы.  
8. Эндпоинты intermediate / results / export.  
9. Стыковка с макетами страниц 1–3.
