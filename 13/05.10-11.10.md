Отчёт команды 13 за 05.10–11.10
Тема проекта
Прогнозирование температуры в Афганистане с использованием методов машинного обучения
Выполненная работа
1. Продолжена подготовка набора климатических данных ERA5-Land за 2010–2025 гг. для выбранных городов Афганистана.
2. Подготовлены данные для обучения моделей прогнозирования среднемесячной температуры.
3. Реализовано сравнение трёх регрессионных моделей: Linear Regression, Random Forest Regressor и Gradient Boosting Regressor.
4. Выполнена оценка качества моделей с использованием метрик MAE и R².
5. Получены следующие результаты:
   Модель	MAE	R²
   Linear Regression	8.918	0.242
   Random Forest	1.481	0.971
   Gradient Boosting	1.416	0.976
6. По результатам сравнения выбрана модель Gradient Boosting, показавшая наименьшее значение MAE и наибольшее значение R² среди проверенных моделей.
7. Обученная модель сохранена в файл temperature_model_v2.pkl.
